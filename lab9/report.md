## Лабораторная работа №9 «Классы с полями типа другого класса»

**Постановка задачи:**

Внести изменения в Домашнюю работу 8:
1. Описать еще один класс, одним из полей которого является поле типа
родительского класса определенной ранее иерархии.
2. Создавать объекты нового класса и демонстрировать работу всех его методов.

**Описание алгоритма:**

1.  Создается некая сцена
2.	Создается заранее подготовленный монстр1
3.	Создается заранее подготовленный монстр2
4.	Пользователю дается выбор класса монстра3
5.	Вызывается метод сцены Rumble
6.  Поочередно удаляются монстры из сцены (иначе они не удаляются, я пока не понял, почему)

**Компиляция:**

    cmake -S . -B build -G Ninja && ninja -C build
  
**Запуск:**

    ./build/main_app
