## Лабораторная работа №12 «Перегрузка операций»

**Постановка задачи:**

Перегрузка операторов: "Класс комплексных чисел". Написать программу, демонстрирующую работу с классом "комплексные числа". В программе должны быть реализованы конструктор по умолчанию, конструктор с параметрами, конструктор копирования. Необходимо переопределить операции присваивания, арифметические операции "+", "*", "-", "/", префиксные и постфиксные инкремент и декремент, логические операции ">", "<", "==", "!=" (Сравнение чисел осуществлять по модулю комплексного числа). Определить дружественные функции ввода-вывода (>>, <<), вывод комплексного числа осуществлять в виде a+b*i.

**Описание алгоритма:**

Поочередно выполняется следущее:

1. Создается объект класса Complex
2. Демонстрируется выполнение соответствующего заданию конструктора, метода или операции

**Программный код:** [main.cpp](./Code/src/main.cpp)

**Компиляция:**

    cmake -S . -B build -G Ninja 
    ninja -C build 
  
**Запуск:**

    ./build/main_app
