## Лабораторная работа №10 «Статические методы и нисходящее пприведение типов»

**Постановка задачи:**

Внести изменения в Домашнюю работу 9:
1. Для последнего нового класса, необходимо реализовать методы изменения
параметров вложенного поля. Использовать нисходящее приведение типов.
2. Для последнего нового класса, необходимо реализовать статический метод для
создания объектов класса.

**Описание алгоритма:**

1. Создается объект класса Scene
2. С помощью статического метода Create создаются подклассы класса Monster a, b и c(по выбору пользователя)
3. Демонстрируется нисходящее привидение типов
4. Демонстрируется работоспособность методов Scene

**Программный код:** [main.cpp](./Code/src/main.cpp

**Компиляция:**

    cmake -S . -B build -G Ninja
    cmake --build build
  
**Запуск:**

    ./build/main_app
