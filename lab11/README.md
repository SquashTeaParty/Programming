## Лабораторная работа №11 «Исключения»»

**Постановка задачи:**

Внести изменения в Домашнее задание 10.
Реализовать обработку исключений. Генерировать и обрабатывать исключения минимум трех разных типов, одним из которых обязательно должно быть исключение-объект класса.

**Описание алгоритма:**

1. Создается объект класса Scene в блоке try
2. С помощью статического метода Create создаются подклассы класса Monster a, b и c(по выбору пользователя с заданием всех параметров)
3. Демонстрируется нисходящее привидение типов
4. Демонстрируется работоспособность методов Scene
5. Удаляются монстры и созданная сцена через вспомогательную функцию
6. При любом исключении отдает управление соотвествующему catch

**Программный код:** [main.cpp](./Code/src/main.cpp

**Компиляция:**

    cmake -S . -B build -G Ninja
    ninja -C build
  
**Запуск:**

    ./build/main_app
